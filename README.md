# 🌊 Waveform (DeepSeek V4 Flash)

A benchmark-built audio visualizer: see how far DeepSeek V4 Flash can take pure Web Audio API + Canvas — no frameworks, no dependencies, no audio files.

**5 modes** (Spectrum, Orbit, Nebula, Wave, Pulse) · **4 generative demo tracks** · **Mic input** · Mobile-first with gesture controls.

## Run

```bash
python3 -m http.server 8000
```
