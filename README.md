# 🌊 Waveform (DeepSeek V4 Flash)

A lightweight, zero-dependency audio visualizer — pure Web Audio API + Canvas.

**5 modes** (Spectrum, Orbit, Nebula, Wave, Pulse) · **4 generative demo tracks** · **Mic input** · Mobile-first with gesture controls.

Built with [DeepSeek V4 Flash (0731)](https://github.com/alexcyterski/waveform-DSV4F) as a benchmark test.

## Run

```bash
python3 -m http.server 8000
```
